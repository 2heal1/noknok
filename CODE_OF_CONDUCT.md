# Code of Conduct · 行为准则

## English

This code applies to participation in the NokNok repository, including issues, pull requests, discussions, and other project-managed spaces.

- Treat people with respect. Welcome different backgrounds and levels of experience.
- Give specific, constructive feedback. Critique ideas and code rather than attacking people.
- Do not harass, threaten, discriminate against, or sexually target others.
- Do not publish another person's private information or credentials without permission.
- Keep discussions relevant and avoid spam or repeated disruption.

For a public concern, open a repository issue without personal or sensitive information. For a private report, use a private contact channel listed by a project maintainer on GitHub. If none is listed, ask for one without posting the details publicly.

Maintainers will review reports and may remove inappropriate content, give a warning, or temporarily or permanently restrict participation. Responses should reflect the context and impact of the behavior. Anyone involved in a report should respect the privacy of the people affected.

## 中文

本准则适用于 NokNok 仓库中的 Issue、Pull Request、讨论区，以及项目管理的其他协作空间。

- 尊重他人，欢迎不同背景和经验水平的参与者。
- 提供具体、建设性的反馈，讨论观点和代码，避免人身攻击。
- 不骚扰、威胁、歧视他人，不发表针对他人的性骚扰言论或行为。
- 未经允许，不公开他人的私人信息或访问凭据。
- 保持讨论相关，不发布垃圾信息或持续干扰协作。

一般问题可以通过仓库 Issue 反馈，不要公开私人或敏感信息。需要私下报告时，请使用维护者在 GitHub 上公布的私人联系渠道；如果没有公布，可以先请求联系渠道，不要公开事件细节。

维护者会审阅反馈，并可根据行为的情境和影响移除不当内容、警告当事人，或暂时、永久限制其参与。参与处理的人应尊重相关人员的隐私。
