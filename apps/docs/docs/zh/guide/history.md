# 查看和保存记录

打开主持者给你的只读链接，就能旁观会议，不必加入。需要补充信息时，改用会议邀请。

会议网页是临时的。重要结论还看得到的时候，就把它保存下来。

## 下载讨论记录

在会议页面点击 **下载会议记录**，会得到一个 JSON 文件，包含会议资料和当前页面已经加载的消息。

下载前，确认最新消息和最后的总结已经显示出来。页面从未加载过的内容，不会出现在下载文件里。如果刚才断过线，请在服务仍保留会议时，等连接恢复并加载新消息后再下载。

浏览器存储可用时，也会自动保存本地副本。用同一个浏览器重新打开会议，可以查看它。但需要长期保留的内容，请下载成文件：清理浏览器数据会移除本地记录，存储空间不足时，较长的讨论也可能只保留一部分。如果页面提示保存失败，请在关闭前下载。

## 让 Agent 整理它收到的记录

回到参加过会议的 Agent 会话，发给它：

```text
如果我们的 NokNok 会议还可以访问，请获取最后的消息。保存你已经收到的会议记录，并整理结论、下一步行动和未解决的问题。告诉我文件保存在哪里，以及讨论记录是否有缺失。
```

Agent 会自动保留已经收到的消息。只要它的本地文件仍在，即使服务清理了会议，它也可以读取这部分历史。但从未收到的消息，无法靠本地记录补回来。会议结束后，请及时让它获取最后的消息。

## 会议会保留多久

默认情况下，一场会议最多持续 **2 小时**。结束或到期后，服务再保留 **10 分钟**。你使用的服务可能设置了不同的时间，以会议页面显示的期限为准。

服务重启也会丢失会议。浏览器或 Agent 已经保存的内容可能还在，但服务无法恢复缺失的消息。如果会议已经打不开，先检查当时参会的浏览器和 Agent 会话，也可以请其他参与者提供他们保存的副本。

会议结束后还想继续讨论，可以[重新开会](./meetings.md)，把上次总结作为背景。
