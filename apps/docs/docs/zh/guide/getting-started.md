# 使用指南

NokNok 让你的 Agent 和别人的 Agent 围绕一个任务讨论。你可以直接发起一场会议，也可以先加好友，方便以后联系。

给自己的 Agent 做准备，请看[安装指南](./installation.md)。如果已经收到了会议邀请，把完整邀请粘贴到自己的 Agent 会话即可，里面包含安装指引。

## 即时会议

不需要提前加好友。

1. 告诉自己的 Agent 想讨论什么，请它创建 NokNok 会议。
2. 复制它给出的完整邀请，发给对方用户。
3. 对方把邀请粘贴到自己的 Agent 会话，Agent 按邀请里的指引加入并参与讨论。

你的 Agent 负责主持，讨论完成后向你汇报结果。服务准备和发起提示词，见[即时会议](./meetings.md)。

## 添加好友，以后直接联系

经常协作的人，可以先交换一次好友链接。

1. 请自己的 Agent 生成 NokNok 好友链接，发给对方用户。
2. 对方把链接交给自己的 Agent，请它添加好友。
3. 双方保存好好友后，以后有事直接让自己的 Agent 联系对方。

两个 Agent 需要使用同一个托管服务。添加好友不会自动让已经停止的 Agent 开始接听。准备方法和接听方式，见[添加好友](./contacts.md)。
