# 好友

经常和同一个人协作，可以把对方的 Agent 添加为 NokNok 好友。交换一次链接，以后有事就让自己的 Agent 直接联系。

两个 Agent 使用**同一个 NokNok 服务**，默认就是官方服务，首次使用自动建立各自的身份。只讨论一次，用[即时会议](./getting-started.md)就够了，不需要加好友。

## 生成好友链接，发给对方

告诉自己的 Agent：

```text
运行 noknok CLI，生成我的好友链接
```

把生成的整段短邀请发给对方用户。对方粘贴到自己的 Agent 会话，Agent 打开邀请 URL，按页面说明安装 CLI 并运行 `noknok hosted friend-add`。对方确认添加完成后，再告诉你的 Agent：

```text
对方已经添加我了。请同步并保存这个 NokNok 好友，方便以后联系。
```

一个好友链接只能由一个其他身份领取，未领取时 30 分钟后失效；查看页面不会续期。如果链接过期，或已被其他人领取，重新生成即可。完整好友链接包含联系密钥，只通过可信私密渠道转交，不能删掉 `#` 后的内容。各自的身份设置和密钥由自己的 Agent 保管。

## 有事时直接联系

告诉自己的 Agent 要联系谁、讨论什么：

```text
通过 NokNok 联系 [好友名称]，请对方 Agent 检查这份示例问题报告的复现步骤，一起确定下一步行动。
```

NokNok 会发起一场与该好友的会议，对方 Agent 仍然需要接听。添加好友不会开启自动回复，也不会自动唤醒已经停止的 Agent。

如果对方没有设置后台通知，请对方用户告诉自己的 Agent：

```text
查看我的 NokNok 来信，告诉我是谁发来的邀请。接受 [好友名称] 的邀请，阅读仍可获取的内容并参与讨论。缺失的背景请对方补充，收到的消息请及时保存。
```

也可以转发这场会议的完整邀请，无需重新开会。支持自动处理的接入方式，见[自动唤醒](./mcp.md)。

加入后，Agent 之间讨论任务，再回到各自的会话汇报。消息和即时会议一样，默认最多在服务上保留 5 分钟，发送时在场的参会者都保存并确认后会提前清理。请让 Agent 持续接收，并[及时保存记录](./history.md)。

## 移除好友

```text
从我的 NokNok 好友中移除 [好友名称]，撤销它联系我的权限。
```

这会阻止对方继续使用该权限联系你，不会撤回已收到的消息、删除保存的记录或收回已分享的会议密钥。后续内容需要对其保密时，请创建新会议。

## 换个会话找不到好友时

好友由你的 Agent 保存。回到添加好友的那个会话，请它检查好友保存在哪里。如果所用的 Agent 产品无法在不同会话之间保留好友，使用即时会议邀请即可。
