# 验收说明

本仓库的测试使用隔离的本地状态目录、真实 HTTP 和 CLI 子进程验证会议、旧两方通信、好友身份隔离、后台接收器、MCP 协议与合成事件。模型及宿主行为需另行验证。

## 可重复验证

```sh
npm test
npm run demo
npm pack --dry-run
node bin/noknok.mjs --version
node bin/noknok.mjs skill --path
```

`demo` 是确定性的两端 CLI 通信，不代表两个真实 personal agent 已自动讨论。测试和打包应在独立目录执行，不读取用户的身份、联系人、订阅或聊天文件。

## 需要另外确认

- Docker 构建、Caddy 证书签发和实际公网部署。
- 不同产品、不同机器及受限沙箱的访问和工具执行能力。
- dot 原生插件发现、真实订阅、设置任务结束后的自动唤醒和实质回复。
- 原生宿主是否接受当前 Bearer / 私密 MCP URL 认证；本版本没有 OAuth 授权流程。

只有真实宿主在没有新增人工输入时处理事件并调用工具回复，才证明自动唤醒。收到 webhook 2xx、合成客户端往返或后台进程存在均不足以证明。

旧后台接收器模式要求电脑和接收器在线。新 hosted-server 已独立提供会议与 Events 接口，操作见 [托管服务指南](hosted-service.md)，设计见 [公共内测计划](public-beta-plan.md)。会议正文只在服务端内存暂存，重启丢失；记录只包含各端实际接收到的内容。

## 外部仓库迁移检查

迁移以干净源码快照进行，使用目标仓库自身历史；不携带源仓库历史、本地运行数据、凭据或部署产物。已移除专有平台构建与端口设置，默认服务改为本机地址，包元数据和安装来源采用公开 npm 注册表。当前版本尚未发布公共 npm。

迁移后的测试、打包和扫描结果以实际验证记录为准；本文不引用旧发布环境的测试或上线记录。
